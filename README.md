### Mortality Biomarker Discovery in Pediatric Critical Influenza Using GSE236877

This project analyzes gene expression data from GSE236877 to identify genes associated with mortality in pediatric patients with critical influenza.

The analysis includes:

Differential expression analysis
Identification of mortality-associated genes
Random Forest machine learning
Feature importance analysis
Confusion matrix and ROC curve evaluation

The Random Forest model achieved a test accuracy of 95.56% and ROC-AUC of 96.83%.

The analysis identified several important candidate genes, including OAS1, HSH2D, IFIH1, IFIT5, IFI44L, MMP9, S100A12, MS4A4A, and others.

The repository contains the complete analysis notebook, figures, and results.

Tools used: Google Colab (Python and R/limma), Pandas, NumPy, Matplotlib, and Scikit-learn.
